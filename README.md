# Bilibili Knowledge Map · B站视频知识地图

把一个UP主、一个合集或一批B站视频，整理成能展开阅读、能回看出处的知识地图。

**先看全貌 → 展开读方法与步骤 → 点击时间回到原片。**

这是共享的Agent工作流程Skill，不是一款独立下载器或托管网站。美术风格由内容和使用者决定。

## 能得到什么

- **HTML学习看板**：按问题组织模块，逐层展开，颜色与字重区分层级。
- **Markdown学习手册**：便于保存、检索和继续编辑的文字底稿。
- **可追溯的来源**：原片链接、真实时间点、字幕或转写记录、覆盖与核验说明。

它会先合并多条视频重复讲述的方法，再保留不同案例、条件和版本差异。归并段落的来源标签直接打开原视频；具体步骤可附带时间定位，不需要先翻到底部索引。

## 如何使用

将本仓库放进你的Agent支持的技能目录。共享技能目录通常可以使用以下方式安装；已有同名目录时请先检查，不覆盖：

```bash
git clone https://github.com/boss-chang2026/bilibili-knowledge-map.git ~/.agents/skills/bilibili-knowledge-map
```

技能的识别、启用与刷新方式取决于Agent。Codex可显式调用：

```text
使用 $bilibili-knowledge-map 整理这个B站合集：<合集链接>。
我想快速了解所有方法，并能查看操作步骤和跳回原视频。
```

也可使用普通语言：

```text
请按照 bilibili-knowledge-map 的流程，把这个UP主的“效率提升”合集
做成可展开的学习看板，并附文字底稿和带时间的原片出处。
主页：<主页链接>
```

其他支持Markdown技能的Agent可以读取 [SKILL.md](SKILL.md) 执行。Agent未自动发现时，直接提供该文件即可；文件存在不等于平台必然自动调用。

## 实际处理过程

1. 核实作者、范围、视频数量和多P信息。
2. 取得完整字幕，或提取音频转写；必要时补看画面。
3. 按读者问题重组模块，合并重复方法，保留差异。
4. 生成可展开的HTML看板、Markdown手册和来源记录。
5. 核对覆盖、链接和时间范围，有条件时抽测实际播放。

默认不固定模块数、页面皮肤或学习主题。只给主页且范围不明确时，会先核实内容再确认范围。

## 需要什么能力

Agent需要能访问公开资料、读写本地文件并制作HTML。没有可获取字幕时，需要可用的音频获取和语音转写能力；画面信息影响操作时，还需要相应的视频或图片分析能力。

本仓库不捆绑模型、媒体、API密钥或第三方程序，也不会因为安装Skill而自动下载依赖。缺少执行能力时，应报告缺口，不把只有标题的列表伪装成完整总结。
